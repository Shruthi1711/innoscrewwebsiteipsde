# INNO-SCREW Website - Deployment Guide

## Overview
This is the INNO-SCREW research project website, a static site hosted on GitHub Pages. The site features:

- **Bilingual interface** (German/English)
- **Dark mode support**
- **Responsive design**
- **News & publication listings**
- **Research infrastructure documentation**
- **Open research data catalog**

## Key Features

### Language Toggle
- Click the "EN/DE" button in the top navigation to switch languages
- Language preference is saved in browser localStorage

### Dark Mode
- Click the moon/sun icon to toggle dark/light theme
- Theme preference is saved in browser localStorage

### Mobile Navigation
- On mobile devices, click the hamburger menu to open/close navigation
- Menu auto-closes when you select a page

### Infrastructure Page
- Click on different screwdriving systems (ASS, RSS, MSS, DSS, KSS) to view details
- System can be selected from URL hash (e.g., `infrastructure.html#ass`)

### News Filtering
- On the news page, use category buttons to filter articles
- "All" shows all news items

## Deployment Instructions

### GitHub Pages (Recommended)

1. **Ensure `.nojekyll` file exists** in the root directory
   - This file tells GitHub to serve files as-is without Jekyll processing

2. **Push to your GitHub repository**
   ```bash
   git add .
   git commit -m "Deploy INNO-SCREW website"
   git push origin main
   ```

3. **Configure GitHub Pages**
   - Go to Settings → Pages
   - Select "Deploy from a branch"
   - Choose the branch and `/root` directory
   - Save

4. **Verify deployment**
   - Your site will be available at `https://yourusername.github.io/innoscrewwebsite/`
   - Check the "Deployments" tab for deployment status

### Local Testing

1. **Run a local server** (requires Python 3)
   ```bash
   # In the website directory
   python3 -m http.server 8000
   ```

2. **Visit** `http://localhost:8000`

3. **Test all features:**
   - Language switching
   - Dark mode toggle
   - Mobile menu (resize to < 768px width)
   - Infrastructure tab switching
   - News category filtering
   - All links and navigation

## Troubleshooting

### Site not loading properly?

1. **Clear browser cache**
   - Hard refresh: `Ctrl+Shift+R` (Windows/Linux) or `Cmd+Shift+R` (Mac)

2. **Check console for errors**
   - Press `F12` to open developer tools
   - Check the Console tab for any JavaScript errors

3. **Verify all assets are present**
   - Check that `/assets/` folder contains:
     - `style.css` - Stylesheets
     - `main.js` - JavaScript functionality
     - `logo.png` - INNO-SCREW logo
     - Images for team members and stations

4. **Language/Theme not persisting?**
   - Ensure localStorage is enabled in your browser
   - Some browsers disable localStorage in private/incognito mode

### Specific pages not working?

- **Infrastructure page tabs**: Check that all `panel-*` IDs match the `data-panel` attributes
- **News filtering**: Verify that `nfbtn` buttons and `nentry` articles have matching `data-cat` values
- **Navigation highlighting**: The current page detection uses filename matching

## Maintenance

### Adding News Items

News items are generated by the build.py script. To add new items:

1. Edit `tools/build.py`
2. Locate the news section
3. Add new entry with:
   - Date
   - Category (`update`, `dataset`, `publication`, `conference`, `transfer`, `infrastructure`)
   - German & English title/content
4. Run: `python3 tools/build.py`
5. This regenerates `news.html`

### Updating Infrastructure Data

1. Edit the infrastructure data in `tools/build.py`
2. Add new systems or update specifications
3. Run: `python3 tools/build.py`
4. Regenerates `infrastructure.html`

### Adding Publications

1. Edit the publications section in `tools/build.py`
2. Add new publication with DOI/links
3. Run: `python3 tools/build.py`
4. Regenerates `publications.html`

## Performance Tips

1. **Images are already optimized** (WebP format with PNG fallbacks)
2. **CSS is minified** - don't expand unless necessary
3. **JavaScript is vanilla** (no external dependencies)
4. **No tracking or analytics** - preserves user privacy
5. **Google Fonts loaded asynchronously** - won't block page load
